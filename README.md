
# PLP Python Week 4 Assignment

This repository contains my Week 4 Python assignment on functions.

## Files

- `welcome.py` - Defines a welcome() function that returns a greeting message for a given name. It is called three times.
- `toolbox.py` - Contains three functions: double() to multiply a number by two, is_pass() to check whether a score is 50 or above, and greet() to generate a greeting with an optional greeting message.

## Reflection

The hardest function to write was greet() because it uses an optional parameter with a default value. I had to understand how Python uses the default greeting when no second argument is provided.
